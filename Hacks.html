DAW Workflow Shortcuts

Stop clicking around menus. Use these essential student keyboard layout shortcuts to speed up your arrangement, sequencing, and mixing.

FL Studio

Quick Slice (Knife)C
Paint Tool (Brush)B
Duplicate SelectionCtrl + B
Quick Quantize NotesCtrl + Q
Link to Mixer TrackCtrl + L
Stretch Audio ToggleShift + M

Ableton Live

Split Audio ClipCtrl + E
Consolidate ClipsCtrl + J
Duplicate Clip/LoopCtrl + D
Insert MIDI ClipCtrl + Shift + M
Toggle Clip/Device ViewShift + Tab
Group Selected TracksCtrl + G

Logic Pro

Split Region at PlayheadCmd + T
Join RegionsCmd + J
Cycle Loop (Toggle)C
Open Piano RollP
Open Mixer WindowX
Repeat RegionR

Pro Tools

Separate ClipCtrl + E
Heal SeparationCtrl + H
Consolidate ClipAlt + Shift + 3
Toggle Mix/Edit WindowCtrl + =
New Track MenuCtrl + Shift + N
Create Fades MenuCtrl + F

*Windows users use Ctrl/Alt. macOS users use Cmd/Option.
